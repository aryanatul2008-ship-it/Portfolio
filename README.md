# Aryan Patil — Personal Portfolio

A sleek, responsive, dark-mode personal developer portfolio built with modern vanilla HTML, CSS, and JavaScript.

---

## 📌 Overview

This repository hosts the source code for my personal portfolio website showcasing my projects, technical toolkit, background, and hackathon achievements as a first-year Computer Science & Engineering student at NITK.

## ✨ Sections & Highlights

- **Hero & Intro:** Overview with interactive vector animation, core focus areas (Artificial Intelligence, Hackathons, UI Design), and quick navigation.
- **Featured Projects:**
  - **[Witness](https://github.com/Omega131/Witness.git)**: A privacy-first evidence preservation tool for activists and journalists. Encrypts and hashes files client-side, anchors proofs onto Celo Sepolia & Polygon Amoy testnet blockchains, and stores encrypted assets on IPFS with optional AI validation.
    - *Tech Stack:* React, Vite, ethers.js, Solidity, Hardhat, IPFS, Gemini API
  - **[Aroha](https://github.com/aryanatul2008-ship-it/Aroha)**: An AI-driven skill acceleration and hiring bridge featuring personalized learning roadmaps, a live coding arena with a no-spoilers AI mentor, and verified job matching.
    - *Tech Stack:* HTML, JavaScript, Tailwind CSS, Node.js, Express, PostgreSQL, Gemini API
- **Log / Story:** Milestones including B.Tech in CSE at NITK, Track Runner-Up at the *Build for Billions Hackathon*, and personal interests.
- **Toolkit:** Breakdown of languages, backend systems, and developer tools (HTML, CSS, JavaScript, Node.js, PostgreSQL, GitHub, VS Code, Vercel, Antigravity).
- **Contact:** One-click links to reach out via email or GitHub.

## 🛠️ Design & Tech Details

- **Design Aesthetic:** Deep space dark theme (`#0b0c26`), glowing ambient lights, glassmorphism blur cards, and responsive fluid typography (`clamp()`).
- **Typography:** [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) for headings and [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) for monospace body text.
- **Performance:** Lightweight, zero-dependency codebase using the native `IntersectionObserver` API for smooth scroll-reveal animations and accessible HTML5 semantics.

## 🚀 Running Locally

No installation or build steps required:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/aryanatul2008-ship-it/Portfolio.git
   cd Portfolio
   ```

2. **Start a local web server:**
   Using Python:
   ```bash
   python -m http.server 8000
   ```
   Or using Node:
   ```bash
   npx serve .
   ```
   *(Or simply open `index.html` directly in your browser)*

3. **Visit:** Open [http://localhost:8000](http://localhost:8000)
